\# ThinkTank



ThinkTank is an AI-powered adaptive cognitive challenge game.



\## Project Objective



ThinkTank presents users with different cognitive challenges,

records observable gameplay behavior such as reaction time,

accuracy, mistakes and decision patterns, and uses machine

learning to analyze performance and adapt future challenges.



\## Challenges



1\. Stroop Challenge

2\. Memory Challenge

3\. Pattern Challenge

4\. Risk Decision

5\. Time Pressure

6\. Decision Dilemma
